# Diagnóstico de Qualidade de Software — PBL 1
**Projeto:** Local Eats


### 1. Sistema lento em horários de pico
* **Atributo de Qualidade Afetado:** Desempenho
* **Justificativa Técnica:** A sobre carga no sistema esta excedendo o tempo de respostas, degradando a experiência do usuário. O sistema não apresenta escalabilidade.

### 2. Telas confusas e pouco intuitivas
* **Atributo de Qualidade Afetado:** Usabilidade
* **Justificativa Técnica:** A interface não facilita para que usuário entenda o sistema, causando um esforço excessivo na interação.

### 3. Buscas incorretas
* **Atributo de Qualidade Afetado:** Adequação Funcional
* **Justificativa Técnica:** O sistema não entrega o resultado preciso para que foi projetado, isso gera falta de confiança no sistema.

### 4. Falhas em determinar modelos de smartphones
* **Atributo de Qualidade Afetado:** Compatibilidade
* **Justificativa Técnica:** O sistema falha ao ser executado em diferentes ambientes, limitando o alcance do público.

### 5. Dificuldade para concluir ações simples
* **Atributo de Qualidade Afetado:** Usabilidade
* **Justificativa Técnica:** Se ações simples são difíceis, o fluxo de navegação está mal projetado.
  
### 6. Avaliações desaparecem ao atualizar a página
* **Atributo de Qualidade Afetado:** Confiabilidade
* **Justificativa Técnica:** Indica falhas no do banco de dados ou no estado da aplicação. O sistema não se comporta de forma consistente, perdendo informações geradas pelo usuário.

### 7. Inconsistências entre web e mobile
* **Atributo de Qualidade Afetado:** Compatibilidade
* **Justificativa Técnica:** O usuário espera que a regra de negócio e os dados sejam idênticos em qualquer ponto de acesso.

## O sistema possui qualidade adequada para continuar em operação?
* O Sistema apresenta riscos e falhas que podem comprometer o negocio. Operar nessas condições pode afastar os usuários.

## Quais aspectos de qualidade do produto estão comprometidas?
* Desempenho, usabilidade e confiabilidade.

## Quais problemas devem ser priorizados?
* Buscas incorretas e a persistência dos dados. O sistema precisa funcionar corretamente. Resolver os erros de busca e o desaparecimento das avaliações é essencial.
